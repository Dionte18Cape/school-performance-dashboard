# School Performance Dashboard  
**Created by Dionte Capleton**

This project explores academic and salary insights across schools using Oracle SQL, Python (Pandas), and Power BI.

---

## Overview
This interactive Power BI dashboard visualizes:
- Academic performance by grade level and school
- Student-to-teacher ratios
- Total and average salaries for principals and teachers
- Budget recommendations based on performance data

---

## Tools Used
- Oracle SQL Developer
- Python (for data cleaning/export)
- Power BI Desktop

---

## Folder Structure
- `PowerBI/`: .pbix dashboard file
- `SQL/`: Queries used to extract and join data
- `Python/`: Notebooks for cleaning and CSV generation
- `images/`: Dashboard previews

---

## Key Insights
- Schools with smaller class sizes perform better academically.
- Fayetteville-Manlius leads in performance and warrants budget prioritization.
- Disparity exists between performance and salary allocation, highlighting retention risks.

---

## Business Problem Tackled
*Which school should receive a budget increase to improve academic performance and sustain staff retention?*
